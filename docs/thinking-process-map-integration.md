# Forest思考過程マップ・形成文脈の閲覧

2026-10-30、段階2の共通文脈取得経路へ移行した。配備・署名・設定・制限の現行仕様は[API接続ガイドの段階2](../api/v1/README.md#10-段階2forestの参照実装)を参照。

- 既存の「思考過程表出化マップを表示」は、同じオーバーレイでマップを表示する。
- 新たにKFカードの「形成文脈を表示」から、産出元APIの文脈パッケージと、送信時点の保存内容を確認できる。
- OK-Coreで有効ユーザー・グループ所属・KF共有を確認する。Forestのユーザー/グループ登録は要求しない。
- Forestの元KF IDを対応表から解決する。旧移行KFは、残っている元ノード参照も署名して利用する。削除済み・存在しない元データは補完しない。
- マップのtrigger画像・ノード・エッジはForestが提供する。文字列の折り返しやversionの配置等、既存の描画を維持する。
- 新方式の署名はパッケージURL・形式・KF・グループ・利用者・時刻・旧参照へ結び付ける。旧マップ専用署名は旧窓口だけで受け付ける。
- DBのテーブル追加・列変更・SQL適用はない。取得時にDBを書き換えない。

## 配備

OK-CoreとForestの段階2ファイルを同じリリースで反映する。秘密値を含む既存設定は上書きしない。登録sourceのcontext_base_url/context_tokenを設定するか、Forestでは従来のphp/forest_process_map_local.phpを利用する。

## データ欠損の扱い

元ノード自体がない旧KFではマップを取得できない。スナップショットがあれば文脈表示で確認できるが、元ノードの復元やDB移行を自動実行しない。
